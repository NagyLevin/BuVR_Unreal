# VR Application for Sonar Visual Training

> University project aiming to help divers learn to evaluate handheld sonar imagery in an immersive VR environment.

## Problem & Goal
Divers using handheld sonars need practice interpreting noisy, ambiguous returns. This project builds a VR training application with adjustable visualization levels to improve understanding and decision‑making.

## Objectives
- Survey existing sonar training tools and related VR apps.
- Build a VR environment with custom visualization pathways (multiple representation modes).
- Implement a sonar simulation (e.g., raycasting-based).
- Add training modes: noisy detections, IMU‑based drift/reconstruction errors, and other realistic issues.
- Prototype and test user interface / user experience patterns for efficient training.

## Planned Features
- Multiple visualization tiers (raw returns, filtered views, reconstructed surfaces).
- Scenario presets with adjustable noise, clutter, and sensor drift.
- Performance and progress tracking (time to detection, accuracy).
- Instructor and trainee modes.

## Tech Stack (suggested)
- Engine: Unreal Engine 5 (Blueprints + C++).
- VR: OpenXR / SteamVR.
- Rendering: Niagara / custom materials for sonar visuals.
